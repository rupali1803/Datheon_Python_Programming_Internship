# Task 3: Automated File Organizer & Cleanup Utility

## Project Description
This project is a Python-based file organizer that automatically organizes files into different folders according to their file extensions.

## Features
- Organizes Documents, Images, Videos, Archives and Code files.
- Automatically creates folders.
- Moves files into their respective folders.
- Displays the total number of files moved.

## Technologies Used
- Python 3
- OS Module
- Shutil Module
- Pathlib Module

## How to Run
1. Install Python 3.
2. Open the project in VS Code.
3. Run the following command:

`python organizer.py`

4. Enter the folder path when prompted.

## Output
Files are automatically arranged into separate folders based on their types.

## Conclusion
This project helps users organize files easily and saves time through automation.
