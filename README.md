
# Datheon Python Programming Internship

## Task 1: Hangman Word Guessing Game

### Project Description
This is a console-based Hangman word guessing game developed using Python.

The user has to guess a hidden word letter by letter within 6 attempts.

### Features
- Random word selection
- Letter guessing
- Maximum 6 wrong attempts
- ASCII Hangman drawing
- Prevents duplicate guesses
- Win and Lose messages

### Technologies Used
- Python 3
- Random Module
- VS Code

### How to Run
1. Install Python 3.
2. Download hangman.py.
3. Open terminal.
4. Run the command:

python hangman.py
